# Mise 設定

`@katsu996/common-utils/mise` として公開されている Mise（旧 rtx）のバージョン管理設定です。

## 継承方法

```bash
# mise.toml
# tools セクションをプロジェクトに追加する場合は以下を参照
```

本パッケージの `exports` から直接設定ファイルを参照できますが、Mise の継承機構は TOML の `extends` 機能に依存しないため、内容を参考にプロジェクトの `mise.toml` に直接記述してください。

## 設定内容

```toml
[tools]
node = "24.19.0"
pnpm = "11.21.0"
```

### node

- **バージョン**: `24.19.0`
- Node.js のバージョンを固定します。

### pnpm

- **バージョン**: `11.21.0`
- pnpm パッケージマネージャーのバージョンを固定します。

## プロジェクトでの使用例

```toml
[tools]
node = "24.19.0"
pnpm = "11.21.0"

# プロジェクト固有のツールを追加
python = "3.12"
```

## 注意事項

- Mise がインストールされていない環境では動作しません
- プロジェクトルートに `mise.toml` を配置してください
- `package.json` の `packageManager` フィールドと `engines` フィールドでも同様のバージョン制約が設定されています
