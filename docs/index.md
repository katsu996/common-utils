# @katsu996/common-utils

TypeScript プロジェクト向けの共通ユーティリティ関数と厳格な開発設定のコレクションです。

## 概要

本パッケージは以下の 3 つの責務を持ちます:

1. **ユーティリティ関数ライブラリ** - `add`, `sub`, `sum` などの数学関数
2. **共有設定ファイルテンプレート** - Biome, TypeScript, Vite, Vitest, Mise の厳格なベース設定
3. **CLI 設定ツール (`katsu-config`)** - 対話形式で設定ファイルを管理するツール
